# Agent instructions for this repo

- Never run `git commit` or `git push` (or otherwise publish changes — e.g.
  flipping GitHub Pages settings, re-running deploy workflows), even if
  asked to "ship" or "finish up." Commits and pushes on this repo are done
  by the user only, on their own schedule. Editing files, staging
  (`git add`), and building/previewing locally is fine without asking.
  This site is live at ravandi.ai — every push deploys it.

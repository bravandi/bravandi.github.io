# Agent instructions for this repo

- Do not run `git commit` or `git push` (or otherwise publish changes — e.g.
  flipping GitHub Pages settings, re-running deploy workflows) unless the
  user explicitly asks for it in that message. Editing files, staging
  (`git add`), and building/previewing locally is fine without asking.
  This site is live at ravandi.ai — every push deploys it.
